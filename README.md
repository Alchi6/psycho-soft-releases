# Psycho Soft — téléchargements

Ce dépôt ne contient que les installateurs de Psycho Soft et le fichier `latest.json` lu par le
logiciel pour se mettre à jour. Le code source n'est pas ici.

## Installer

1. Ouvrir la page [Releases](../../releases/latest).
2. Télécharger `Psycho Soft_…_x64-setup.exe` et le lancer.

Ensuite, le logiciel se met à jour tout seul à chaque lancement.
